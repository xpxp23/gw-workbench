# 🏛️ 公文与材料智能工作台 (GW-Workbench v2.0.2)
**专为银河麒麟 Kylin V10 (海光 3350) 与局域网跨系统协同打造**

## 一、快速启动

```bash
chmod +x start.sh wb.py server.py
./start.sh
```
- **本机主理人直连（自动免密编辑 + 一键调起麒麟 WPS 与文件管理器）**：`http://127.0.0.1:8090`
- **局域网同事访问（支持麒麟与 Windows 浏览器）**：`http://<你的局域网IP>:8090`
  - 同事默认访问密码：`123456`（浏览器自动长期记住，默认防误触“浏览下载模式”）
  - 主理人编辑模式口令：`8888`（本机 `127.0.0.1` 打开默认免密开启）
- **生成银河麒麟桌面快捷方式**：`./start.sh --desktop`
- **后台静默运行 / 停止**：`./start.sh --bg` / `./start.sh --stop`

## 二、v2.0.2 细节打磨（文件柜交互）

1. **文件名完整显示**：事项卡片“来文原件 / 我写的材料”里的文件名不再截成半截，占满整行、自动换行；WPS / ⇄ / 下等操作按钮排到文件名下方右侧。
2. **删除按钮移到预览页**：列表行不再放 🗑（容易误点、也挤占文件名宽度），改为点开文件后在预览抽屉右上角【🗑 删除】，删除时可勾选“同时删掉本机硬盘副本”。
3. **预览页新增【📂 打开目录】**：在“复制路径”旁边，本机点击直接在本机文件管理器（peony 等）中打开该文件所在文件夹，省掉复制路径再去粘贴。

## 三、v2.0.1 修补（用法上的三处改动）

1. **导入公文不再产出“笔记文件”**：Agent（MCP / `wb.py` / 本机 JSON API）导入来文时，只需写好**核心要求**与**待办要求细项**两块；`01_办理要点.md`、职责原文摘录、说明书骨架这类中间产物不再往“我写的材料”里塞。`wb_add_task` 新增 `checklist` 与 `auto_ai` 参数，待办细项可以在入库时一次写准。
2. **进展记录区不再“内容已滚动、底部却空一大块”**：三栏改为按各自内容高度收缩，进展流水原来卡死在 115px，现按内容自然展开（超过 300px 才滚动）。
3. **材料可直接删除**（v2.0.2 起入口移到预览页删除按钮）。

## 四、v2.0.0 终极完善亮点

1. **双栏对照撰稿工作台（Split-Screen Drafting Studio）**：
   - 点击任意事项卡片上的【✍️ 双栏对照写材料】或预览抽屉右上角【📖 开启双栏对照】，即可开启**左看参考旧稿/来文要求、右写新材料**的双栏工作台。
   - 左栏支持一键切换查看本事项来文原文、关联参考旧稿或库内常用范文，选中任意句子点击【➕ 插入选中段落至右栏】即可摘抄。
   - 右栏内置**实时字数与段落统计（自动提示是否符合 300 字以内简报/亮点要求）**、**公文一/（一）/1./统计表/落款快捷插入栏**以及 **`Ctrl + S` 极速落盘保存**。
2. **真·双向对等同步（含 `00_事项要求与进展.md` 本地修改反向同步）**：
   - 即使不打开网页，直接在本地文件夹里用编辑器（如 Quilla / Typora / WPS）修改 `00_事项要求与进展.md` 中的 `- [x]` 待办勾选状态或新增进展流水，工作台也能通过文件级 `(mtime, size)` 快照自动感知并**反向同步回 SQLite 数据库**。
3. **微信通知截图 `Ctrl + V` 直接粘贴 & 卡片细项行内改删**：
   - 在顶部全能投喂台直接按 `Ctrl + V` 即可将微信群通知截图或复制的文件粘贴入库。
   - 事项卡片支持视觉完成度进度条，且每条待办细项支持悬停直接行内改字（`✏️`）或删除（`×`）。
4. **GB/T 9704—2012 国标公文 `.docx` 完整排版（含 `— 1 —` 页码页脚与内嵌表格）**：
   - 内置纯 Python OpenXML 国标公文生成器（并支持联动外部 `xkl-gw` CLI），自动生成带 37mm/28mm 页边距、二号方正小标宋标题、三号黑体/楷体/仿宋正文、28 磅固定行距、Markdown 表格转 `<w:tbl>` 以及四号宋体 `— 1 —` 页码页脚的标准 `.docx` 公文。
5. **SQLite `FTS5` 中文 Bigram 毫秒级全文检索 + 原生 MCP Server (`python3 wb.py mcp`)**：
   - 真正启用 `documents_fts` 倒排索引 `MATCH` 查询，数千份历史公文毫秒级高亮召回；搜索结果支持【🎯 定位事项】平滑滚动与脉冲高亮。
