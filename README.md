## v3.0.3 更新（修复示例数据删除后自动重建）

### 问题根因
`seed_demo_data_if_empty()` 原先只判断「表是否为空」：

```python
rec_cnt = COUNT(*) FROM recurring_rules
if rec_cnt == 0:   # ← 只要表空了就重新灌示例
    INSERT INTO recurring_rules ...   # 两个示例周期规则
if arch_cnt == 0:  ...                # 两个示例归档包
if imp_cnt  == 0:  ...                # 两条示例重要事项记录
if task_cnt == 0:  ...                # 一个示例事项
```

而该函数在**每次服务启动**时都会被 `run_server()` 调用。所以把示例删光 → 重启 → 表为空 → 重新灌入，表现为「删了又莫名其妙自己出来」。受影响的栏目共四个：**周期派生、重要事项记录、资料存档、工作台待办**。

### 修复
1. **一次性闸门**：config 新增 `seed_demo_done`（默认 `true`）。示例只会在全新部署且显式允许时灌入一次，灌完立即落标记，此后任何启动都不再生成。
2. **默认不灌示例**：config 新增 `demo_data_enabled`（默认 `false`）。正常使用环境完全不会有示例数据。
3. **一键清理入口**：设置页 →「🧹 示例数据清理」。打开时自动检测残留示例并显示数量，点按钮可一次性清除，且**同时删除对应的本地文件夹**。清理后自动把 `seed_demo_done` 置 `true`。
4. **精确识别，不误伤**：清理依据标题/文号的**精确匹配**（见 `_demo_signatures()`），不做任何模糊删除。你自己建的同名近似内容不受影响。

### 接口
- `GET /api/demo/status` — 返回残留示例数量、`seed_demo_done`、`demo_data_enabled`
- `POST /api/demo/purge` — 需主理人权限，body `{"delete_disk": true}`，返回各类清理计数

### 自查结论（其他栏目）
前端无示例注入逻辑；后端仅 `seed_demo_data_if_empty()` 一处会生成示例，且只被 `run_server()` 调用一次。除此之外，各栏目的「为空」判断（`list_physical_categories` 等）只用于生成空分类目录，不会产生内容。故四个栏目均已覆盖。

## v3.0.2 更新（访问控制与保密加固）

**背景**：局域网范围较大，仅靠密码保护不够。新增 IP 白名单，并清除界面上对默认密码的提示。

### 1. IP 访问白名单
在【⚙️ 设置 → IP 访问白名单】中配置，一行一条，保存即时生效（无需重启）。

| 写法 | 含义 |
|---|---|
| `172.19.51.*` | 整段（等价 `172.19.51.0/24`） |
| `172.19.51.0/24` | CIDR 网段 |
| `172.19.51.69` | 单个 IP |

- **不在名单内的设备直接被断开 TCP 连接**，不回任何 HTTP 响应，浏览器只会显示"无法访问此网站"。对外不透露任何规则信息。
- **`127.0.0.1` 与 `::1` 永远放行**，保证本机始终能进设置页改回配置。
- **白名单为空 = 不限制**，此时设置页顶部会显示黄色警告。
- 服务只监听 IPv4（`0.0.0.0`），本来就不接收 IPv6 请求；代码中对 IPv6 来源也默认拒绝，作为额外防御。
- 保存时若白名单不包含本机局域网 IP，会弹确认框提醒"保存后仅 127.0.0.1 可用"。

### 2. 访问记录（仅本机可见）
设置页底部新增访问记录面板，最近 300 条滚动保存在内存中，界面展示最近 100 条：
- 时间 / 来源 IP / 请求方法与路径 / 结果（✅ 放行 · ⛔ 拦截 · 🔑 密码错误）
- 可切换「全部 / 仅拦截 / 密码错误」，汇总行显示各类计数与当前生效的白名单
- `GET /api/access-log?limit=N`，非本机访问返回 403

被拦截的请求同时会写入 `data/server.log`，形如：
```
⛔ [IP拦截] 2.0.0.1 - GET /api/auth/status (2.0.0.1 不在白名单内)
```

### 3. 移除默认密码提示
登录弹层、编辑模式口令弹层、设置页输入框占位符中原有的 `默认 123456` / `（默认 8888）` 提示全部删除，启动日志也不再打印访问密码。密码值本身未改动，仍可通过设置页修改。

## v3.0.1 更新（资料存档页 UI 重构）

**问题**：v3.0.0 的资料存档是“一条占满整页”的展开式长卡片，每条都把音频播放器、九宫格照片、纪要全文、文件清单全部铺开，攒到三五条就翻不动了。

**改法**：

1. **卡片网格化**：每条归档包压缩成一块紧凑磁贴（封面缩略图 + 两行标题 + 两行纪要摘要 + 资源计数徽标），`auto-fit` 自适应列数，宽屏一行 3～4 块。
2. **按月分组 + 折叠**：默认按 `归档日期` 的月份分组，组头显示「2026-11 · 5 个包」并可一键收起/展开；当月的组默认展开，历史月份收起。
3. **两种视图 × 两种密度**，工具栏可切，选择记在 `localStorage`：
   - 视图：`按月份分组` / `平铺全部`
   - 密度：`卡片`（300px 起） / `紧凑`（215px 起，一屏看更多）
4. **详情抽屉**：点磁贴不再页面内展开，而是从右侧滑出抽屉单独展示该包的全部内容（纪要全文、音频、照片灯箱、文件清单、追加文件/编辑/置顶/打包下载/删除）。抽屉与文档预览复用同一容器，通过 `setDrawerMode('archive' | 'doc')` 切换，关闭抽屉自动回到网格。
5. **其他**：标题/纪要支持关键词高亮；磁贴可键盘聚焦（`Tab` + `Enter`/`Space` 打开）；「定位卡片」跳转时会自动展开目标所在的月份分组。


## 一、快速启动

```bash
chmod +x start.sh wb.py server.py
./start.sh
```
- **本机主理人直连（自动免密编辑 + 一键调起麒麟 WPS 与文件管理器）**：`http://127.0.0.1:8090`
- **局域网同事访问（支持麒麟与 Windows 浏览器）**：`http://<你的局域网IP>:8090`
  - 访问密码与主理人编辑口令请在工作台【⚙️ 设置】中自行设定，脚本与界面均不显示当前值
  - 本机 `127.0.0.1` 默认免密开启编辑模式
- **IP 白名单（v3.0.2 起）**：默认只允许 `172.19.51.*` 访问，不在名单内的设备会被直接断开连接。在【⚙️ 设置 → 访问控制】中修改。
- **生成银河麒麟桌面快捷方式**：`./start.sh --desktop`
- **后台静默运行 / 停止**：`./start.sh --bg` / `./start.sh --stop`
