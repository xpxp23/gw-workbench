# 🏛️ 公文与材料智能工作台 (GW-Workbench v3.0.0)
**专为银河麒麟 Kylin V10 (海光 3350) 与局域网跨系统协同打造 · 六栏目四维政务知识资产平台**

## 一、快速启动

```bash
chmod +x start.sh wb.py server.py
./start.sh
```
- **本机主理人直连（自动免密编辑 + 一键调起麒麟 WPS 与文件管理器）**：`http://127.0.0.1:8090`
- **局域网同事访问（支持麒麟与 Windows 浏览器）**：`http://<你的局域网IP>:8090`
  - 同事默认访问密码：`123456`（浏览器自动长期记住，默认防误触“浏览下载模式”）
  - 主理人编辑模式口令：`8888`（本机 `127.0.0.1` 打开默认免密开启）
- **生成银河麒麟桌面快捷方式**：`./start.sh --desktop`
- **后台静默运行 / 停止**：`./start.sh --bg` / `./start.sh --stop`

## 二、v3.0.0 重大架构升级亮点（六大栏目 + 全栈体验跃升）

### 1. 新增第五栏目：【📦 资料存档】（按次聚合的多媒体活动归档包）
- **自定义多分类管理**：预置 `01_会议记录`、`02_培训课件`、`03_下沉督导照片`、`04_应急演练档案`、`05_宣传与专项资料`，支持自由新建、重命名、合并与删除分类。
- **按“标题/次”一键打包存入**：如输入 `11.17会议记录` 或 `11.18xx事项下沉照片`，可一次性拖入**会议录音（`.mp3/.m4a/.wav`）、现场照片（多张 `.jpg/.png`）、培训课件（`.pptx/.pdf`）、签到表（`.xlsx`）**并附上会议纪要文本，支持向已有归档包随时拖拽追加文件。
- **控制台多模态内联直览**：归档包卡片直接内嵌**原生音频播放器（免下载听录音）**、**现场照片九宫格缩略图（点击开启全屏灯箱翻看大图）**、**PPT/Word/Excel 结构化在线预览**与**一键打包下载 `.zip`**。
- **本地物理目录双向同步**：对应 `workspace_files/资料存档/<分类>/<日期_标题>/`，在麒麟文件管理器中直接新建文件夹放入照片或录音，工作台自动识别生成归档包。

### 2. 新增第六栏目：【📌 重要事项记录】（左树右读零跳转常备知识库）
- **常备底数与预案一秒直读**：专为 `高密汛情基本情况`、`地震应急预案`、`重点行业企业底数`、`应急指挥通讯录` 等高频查阅内容设计，同样支持自定义多分类。
- **左树导航 + 右侧全宽直读画布（Instant Reader）**：点击左侧任意条目，右侧零弹窗、零跳转直接铺满展示完整内容。
- **文本 + Word / PDF / Excel 原件内嵌直读**：
  - 支持直接编写 Markdown 结构化正文与表格；
  - 挂载 `.xlsx / .csv` 台账时，直接在页面内渲染为**带实时行过滤搜索框的交互式数据网格**（输入镇街或水库名即刻筛选）；
  - 挂载 `.docx` 公文时，直接按段落与内嵌表格仿真渲染；
  - 挂载 `.pdf` 预案时，直接内嵌浏览器原生 PDF 阅读器与纯文本速查双视图。

### 3. 全量修复 12 处核心 Bug 与性能瓶颈
- **全格式零依赖解析**：内置纯 Python 标准库 `.pptx` 课件与 `.xlsx` 表格解析器，不装第三方库也能 100% 建立 FTS5 全文索引与在线预览。
- **FTS5 混合词精准召回**：修复搜 `11.17会议记录` 丢弃数字前缀的缺陷，支持日期编号与中文双字词联合毫秒级检索。
- **国标排版精准模式控制**：修复 `report` 汇报模式因来文字号非空而误加红头的 Bug，新增默认单位署名配置项。
- **紧凑驾驶舱与防误触保护**：重构首屏高度分配，释放 300px+ 核心工作区；升级 Markdown 表格渲染器；双栏写稿抽屉新增未保存离开拦截与本地自动草稿保护。
- **14 个原生 MCP Agent 工具**：`python3 wb.py mcp` 新增对【资料存档】与【重要事项记录】的完整读写支持。
