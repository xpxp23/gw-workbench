# 🏛️ 公文与材料智能工作台 (GW-Workbench v1.0.0)
**专为银河麒麟 Kylin V10 (海光 3350) 与局域网跨系统协同打造**

## 一、10 秒快速启动

在银河麒麟终端（或双击脚本）进入本项目目录：

```bash
chmod +x start.sh wb.py
./start.sh
```
- **你自己的电脑访问（自动免密开启主理人编辑模式）**：`http://127.0.0.1:8090`
- **局域网内同事访问（支持麒麟与 Windows 浏览器）**：`http://<你的局域网IP>:8090`
  - 同事默认访问密码：`123456`（浏览器输入一次自动记住一年，默认处于防误触“浏览与下载模式”）
  - 主理人编辑模式切换口令：`8888`（你本机 `127.0.0.1` 打开默认已自动解锁）
- **生成银河麒麟桌面快捷方式图标**：
  ```bash
  ./start.sh --desktop
  ```
- **后台静默常驻运行 / 停止**：
  ```bash
  ./start.sh --bg
  ./start.sh --stop
  ```

## 二、核心特性一览

1. **全能极速投喂 & AI 自动填表**：
   - 支持直接粘贴**微信群通知、电话记录**或拖拽 **`.ofd`（党政机关电子公文）、`.docx`、`.pdf`、`.wps`、`.doc`、`.txt`** 进入顶部投喂框，自动抽提文号、来文单位、紧急度、截止时间、核心要求与可打钩的待办细项（Checklist）。
   - 同时支持配置兼容 OpenAI 接口的在线/内网大模型 API，以及内置零依赖“政务公文规则拆解引擎”（未配 API Key 或纯内网离线也可秒级拆解）。
2. **100% 本地物理文件夹双向对应（不开系统也能找文件）**：
   - 所有文件明文存放在 `./workspace_files/` 下的物理分类目录中（`01_防灾减灾`、`02_隐患排查与安全生产`、`03_综合汇报与总结`、`04_上级日常通知`、`05_历史公文归档`，支持随时新建目录）。
   - **一事项一专属文件夹**：每个工作事项自动生成独立文件夹，内含来文原件、你写的材料，以及自动同步生成的 **`00_事项要求与进展.md`**（记录微信原文、要求细项与进展流水）。
   - **WPS 本地改稿免重传**：你直接在本地文件夹用 WPS 修改保存材料或塞入新定稿，工作台自动检测变更并刷新全文索引，无需去网页重新上传。
3. **独立的【公文与材料库（分类归纳中心）】**：
   - 支持按业务目录、性质（我写的材料 / 常用范文 / 上级来文 / 历史公文）、多维标签（Tags）整理归纳；网页端移动分类会真实移动本地硬盘文件。
   - **免打开 WPS 在线预览复制正文**：点开任何公文或材料，右侧抽屉直接展示完整纯文本，一键复制段落用于写新材料。
   - **历史公文批量入库**：支持网页批量拖入，或直接填入本机历史公文文件夹路径一键扫描建库，按需一键转为工作台待办。
4. **强搜索（仅标题 vs 标题+正文 + AI 智能检索）**：
   - 毫秒级切换 `[仅搜标题/文号]` 与 `[标题 + 正文内容]`。
   - 支持 **🤖 AI 智能搜索与问答**（两段式初筛 + 语义精筛汇总），同时在每个新事项下方自动推荐库内相似的 **💡 参考旧稿**。
5. **本地 Agent 零障碍操控接口**：
   - 详见根目录 `AGENT_GUIDE.md` 与命令行工具 `wb.py`。
