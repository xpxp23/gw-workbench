# 🏛️ 公文与材料智能工作台 (GW-Workbench v1.2.0)
**专为银河麒麟 Kylin V10 (海光 3350) 与局域网跨系统协同打造**

## 一、快速启动

```bash
chmod +x start.sh wb.py server.py
./start.sh
```
- **本机主理人直连（自动免密编辑 + 一键调起麒麟 WPS 与文件管理器）**：`http://127.0.0.1:8090`
- **局域网同事访问（支持麒麟与 Windows 浏览器）**：`http://<你的局域网IP>:8090`
  - 同事默认访问密码：`123456`（浏览器自动长期记住，默认防误触“浏览下载模式”）
  - 主理人编辑模式口令：`8888`（本机 `127.0.0.1` 打开默认免密开启）
- **生成银河麒麟桌面快捷方式**：`./start.sh --desktop`
- **后台静默运行 / 停止**：`./start.sh --bg` / `./start.sh --stop`

## 二、v1.2.0 核心升级亮点

1. **与 `xkl-gw` 及银河麒麟 WPS 深度联动（内置 GB/T 9704—2012 国标公文排版引擎）**：
   - **在线免 WPS 直接写稿改稿**：点击任意事项上的【✍️ 在线写材料】或右侧预览抽屉的【✍️ 在线写稿/改稿】，直接在浏览器中撰写或修改材料并实时落盘到事项本地文件夹。
   - **一键排版导出国标 `.docx` 公文**：内置符合 `GB/T 9704—2012` 标准的纯 Python OpenXML 公文排版器（同时支持联动外部 `xkl-gw` CLI），支持【综合汇报/方案模式】与【带红头文号的正式公文模式】，自动处理 37mm/28mm 国标页边距、二号方正小标宋标题、三号黑体/楷体/仿宋三级标题及 28 磅固定行距。
   - **本机一键调起麒麟 WPS 与文件管理器**：在主机上点击【🖥️ WPS】或【📂 打开目录】即可直接调用银河麒麟系统桌面 WPS 或文件管理器。
2. **周期性 / 常态化工作自动派生引擎（周报/月报/值班调度）**：
   - 支持配置每周、每月、每季度或自定义天数的常态化工作规则，到期自动创建事项专属文件夹，并自动关联上一期写好的定稿材料作为本期参考底稿。
3. **原生 MCP Server 协议支持 (`python3 wb.py mcp`)**：
   - 内置标准 JSON-RPC 2.0 `stdio` MCP Server，支持一键挂载到 Claude Desktop / Cline / Roo Code / Cursor 等本地 Agent 中。
4. **物理分类目录重构与海量文件防卡顿架构**：
   - 支持在【公文与材料库】左侧直接**重命名/合并物理分类目录**、**拖拽文件行至左侧目录完成物理移动**、**多选文件批量移动分类/批量加标签/批量打包下载**。
   - 扫描导入本机历史公文文件夹时，支持**按主题词自动智能分拣至业务分类**，并自动将原多级子目录名保存为文件标签。
   - 底层全面启用 **SQLite FTS5 全文倒排索引虚拟表 + 列表冷热字段分离 + 目录级 `mtime` 快照缓存 + 前端乐观局部 DOM 更新与分页渲染**，即使存入数千份历史公文也保持毫秒级响应、零闪烁不丢焦点。
